# OpenClaw IO Intelligence provider

Official OpenClaw provider plugin for IO Intelligence (io.net)'s
OpenAI-compatible API.

## Install

```sh
openclaw plugins install @openclaw/ionet-provider
openclaw gateway restart
```

## Docs

See `docs/providers/ionet.md` in the OpenClaw repository, or the published
docs at `https://docs.openclaw.ai/providers/ionet`.
